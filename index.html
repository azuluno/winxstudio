WinX Studio guide

Build a Rainmeter skin visually, connect Home Assistant, then export a ready-to-install file.

Connect Home Assistant

Open Connection, enter your URL, port, and long-lived access token. The token is used for REST requests from this browser.

Add entities

Drop a Button, Switch, Slider, or Sensor tile onto the canvas. Select it, choose its domain, and enter an entity ID such as light.living_room.

Build a widget

Drag assets to position them. Use Width, Height, Corner radius, Opacity, and Accent color in the Inspector. Set radius to 100 for a circle.

Import and export

Export saves the editable project as JSON. Import restores widget positions and settings for continued editing.

Validate and build

Validate checks the canvas and entity bindings. Build skin downloads a Rainmeter .ini with runtime variables for Home Assistant.

Live state syncing

When connected, WinX polls bound entities every 10 seconds. Switches and buttons call their matching Home Assistant service.
